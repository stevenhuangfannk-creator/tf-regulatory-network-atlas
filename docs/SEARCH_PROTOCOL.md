# 方法与数据来源核查 / Source audit protocol

核查日期：2026-10-08（Asia/Shanghai）。本次为目标导向的范围调研，不声称系统综述或全面检索。

研究问题：在人牙周/种植体周炎症数据中，哪些方法适合 TF activity、GRN inference、co-expression、upstream signaling、perturbation 与 multiomics？它们的输入条件、证据边界、许可证与实际可运行性如何？

优先来源：原始论文 DOI/Crossref/PubMed 元数据；官方 GitHub API、README、许可证与官方教程；GEO SOFT/CELLxGENE API/Zenodo 元数据。逐条保留 URL、请求日期、响应状态与提取字段。官方资源与实际运行日志是软件状态的依据；最近 commit 不等于通过当前环境验证。

纳入：用户指定方法，以及有原始论文、公开实现且补充不同分析定位的方法。排除：没有可追溯实现或数据要求不明的宣传性条目。论文按 DOI 去重；软件按官方仓库去重；不同版本/数据集分开标注。未读全文时不得称全文验证。无法获取的来源记入失败日志，不能据此判断不存在。

分析优先级：同一研究有可核查供体与条件的真实人牙周数据；其次只读复用审计过的本地人数据并显式保留批次混杂；不把细胞数当作独立重复。高级方法缺少输入时只建立资源卡及待实现图形索引。
